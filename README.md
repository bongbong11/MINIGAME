# SillyTavern 심심풀이

SillyTavern 안에서 자체 구동되는 솔리테어·아이템 벽돌깨기·스도쿠 확장입니다. 외부 게임 사이트나 AI 호출, 외부 그래픽·음원 자산을 사용하지 않습니다.

## 설치

1. 이 폴더 안의 파일을 GitHub 저장소 최상단에 올립니다. ZIP 파일 자체를 올리는 방식이 아닙니다.
2. SillyTavern의 `확장 → 확장 설치`에서 GitHub 저장소 주소로 설치합니다.
3. SillyTavern을 새로고침합니다.

## 실행

채팅 입력창에서 `/minigame`을 실행하면 크기를 조절할 수 있는 플로팅 게임 창이 열립니다. 채팅 메시지를 생성하거나 전송하지 않습니다.

## 게임

- 솔리테어: 힌트, 이전 동작, 더블클릭 자동 이동
- 아이템 벽돌깨기: 100개 레벨, 7종 아이템, 진행 저장, 모바일 터치·PC 마우스·키보드 조작
- 스도쿠: 유일해 검증된 퍼즐, 메모, 힌트, 이전 동작, 진행 저장

확장에 외부 이미지·아이콘·폰트·음원을 포함하지 않습니다.
