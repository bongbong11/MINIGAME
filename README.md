# SillyTavern 심심풀이

SillyTavern 안에서 자체 구동되는 미니게임 확장입니다. 외부 게임 사이트나 AI 호출, 외부 그래픽·음원 자산을 사용하지 않습니다.

## 설치

1. 이 폴더 안의 파일을 GitHub 저장소 최상단에 올립니다. ZIP 파일 자체를 올리는 방식이 아닙니다.
2. SillyTavern의 `확장 → 확장 설치`에서 GitHub 저장소 주소로 설치합니다.
3. SillyTavern을 새로고침합니다.

## 실행

입력창 옆의 마법봉 메뉴에서 게임패드 아이콘이 표시된 `심심풀이`를 누르거나, 채팅 입력창에서 `/minigame`을 실행합니다. 두 방법 모두 크기를 조절할 수 있는 같은 플로팅 게임 창을 열며, 채팅 메시지를 생성하거나 전송하지 않습니다.

## 게임

- 솔리테어: 힌트, 이전 동작, 더블클릭 자동 이동
- 아이템 벽돌깨기: 100개 레벨, 7종 아이템, 진행 저장, 모바일 터치·PC 마우스·키보드 조작
- 스네이크: 6개 맵, 점수·최고점수·시간, 귀여운 먹이, 직접 합성한 효과음
- 슬라이드 퍼즐: 3×3 쉬움·4×4 어려움, 풀 수 있는 배치만 생성, 클릭·스와이프·방향키
- 동물 보석 매치3: 단계별 수집 목표, 이동 제한, 2×2·4개·5개 특수 폭발, 연쇄, 직접 합성한 효과음
- 스도쿠: 유일해 검증된 퍼즐, 메모, 힌트, 이전 동작, 진행 저장

확장에 외부 이미지·아이콘·폰트·음원을 포함하지 않습니다.

## 그남의 집 포인트 연동

두 확장을 함께 설치하면 그남의 집 룰렛 창에서 `포인트 벌러가기`로 심심풀이를 열 수 있습니다. 게임에서 새로 달성한 결과를 그남의 집 포인트로 지급합니다. 심심풀이만 설치한 경우에는 보상 알림이 나타나지 않습니다.

- 스네이크: 5점마다 5P
- 벽돌깨기: 100점마다 5P
- 슬라이드 퍼즐 완료: 10P
- 매치3 목표 달성: 15P
- 솔리테어 완성: 20P
- 스도쿠 완성: 25P

저장돼 있던 완료 화면을 다시 열기만 해서는 포인트가 지급되지 않습니다.
